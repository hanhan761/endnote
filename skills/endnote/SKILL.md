# endnote

end 的时候 note 一下。使用公共通知 API 为用户的实验配置邮件提醒。
默认端点 https://am.matterswarm.com/endnote，用户提供的 ENDNOTE_URL 优先。
服务部署在授权的 4090 workstation；此技能不授予任何 SSH 或服务器维护权限。

## 接入

使用本技能的 scripts/endnote.py（标准库，无安装依赖），或用户项目中的 endnote.client SDK。
填邮箱直接使用，不要求验证码或让用户手工申请密钥。网页和客户端自动生成当前任务的访问凭据。
收件邮箱优先使用用户本次指定值，再读取 ~/.config/endnote/preferences.json 或 credentials.json 的 email。
用户已指定并授权沿用的邮箱无需重复询问；没有已知邮箱才询问，不猜测地址。真实邮箱和凭据只能保存在用户私有配置中，不能进入共享技能或 Git。
没有账号时客户端自动调用 /v1/quick/tasks；已有私有账号配置可继续复用。指定新邮箱时使用该地址的直接创建流程。
任务创建、开始监控时默认发送 [开始] 邮件，附带该邮箱全部任务的私有状态看板链接；notify_start=False 可关闭开始通知。开始不等于已确认实验命令执行，先配置好真实命令并及时接入。
看板跨账号与浏览器按收件邮箱汇总任务，用紧凑表格显示状态、失联、运行时长和最新指标，每 5 秒自动更新。详细趋势按需展开，不要求用户手动刷新。
已结束的任务可以归档并从默认总览移走，也可恢复。归档只整理邮箱看板，不删除记录、不终止实验；仅在用户要求整理时操作，不能自动隐藏真实失败来让结果看起来更好。没有上报的进度不编造百分比。
看板链接只出现在邮件正文，不能用邮箱或单个任务密钥获取；不索取、不公开、不转发这个链接。
开始邮件也计入原有发信限额，达到限额时可能延迟，不能声称立即送达。
首次创建会自动发送一封测试邮件。每封邮件都有一键屏蔽链接：点击后该邮箱全局加入黑名单，取消待发邮件并停止相关任务；后续任何调用方都不能再向它发信。不要替用户点击这个链接。
公开直接创建接口使用固定邮件模板，每邮箱每天最多创建 3 个任务、尝试发送 3 封邮件；不发送自定义正文。
任务凭据自动管理，仅通过 HTTPS 发送，不放进聊天、日志或 Git。

配置用户需要的触发条件。完成、失败和 300 秒无心跳为适合长实验的默认；
设置运行时长或指标规则时依据真实任务需求，不编造收敛阈值。
公开接口使用固定模板；已有私有账号的模板能力保持兼容。
每条指标规则命中后提醒一次，不执行用户提供的代码或表达式。

## 多实验命名与邮件识别

接入时根据实际上下文给每个实验取可识别的名字，包含项目或目标、模型或数据集、能区分本轮的关键参数及轮次。
例如“图像分类 ResNet50 seed42 第3次”；不同配置或重跑不要都叫 experiment、test、模型训练。
优先采用用户已有的实验名；根据已知命令和配置直接补足区别，不重复询问，也不编造模型、参数或结果。
名称限 60 字符，使用文字、数字、空格、括号或连字符，不包含密钥、真实邮箱或敏感路径。
默认邮件标题为“[endnote][开始/成功/失败/中断/超时/指标达标] 实验名称 · #任务编号前8位”。
同名实验也能通过编号区分；邮件正文附完整任务 ID 和创建时间。记录名称与完整 ID 的对应关系，供用户核对。
已有账号可自定义标题，使用 $name、$reason、$task_id；不要使用省略实验名称的笼统模板。公开入口自动使用上述固定标题。

把已授权的实验命令包起来：
python scripts/endnote.py run --name "图像分类 ResNet50 seed42 第3次" -- python train.py

包装器在其执行机器运行原实验，不把命令发送给服务器。
遵守用户已选定的计算机器；远程实验应把客户端放到该机器运行，不能默默在控制机启动。
在 Windows 上非交互子进程必须隐藏窗口；本脚本已设置 CREATE_NO_WINDOW。
如果用户已经运行了实验，不重启或重复启动它；在原代码或外部监控流程中接入事件 API。

指标提醒需要训练代码显式调用 metric，包装器不会解析日志。
自动心跳只说明上报进程活着；要检测无进展，应在关键步骤上报心跳或指标。
保留实验原退出码，不用通知异常掩盖实验异常，不发送可能包含秘密的完整 traceback。

## 验证

记录非秘密的任务 ID，检查自己的任务详情和通知状态。
结束事件应是 succeeded / failed；API 成功仅证明接收事件。
通知 pending 表示待发，sent 表示 SMTP 接受，dead 表示重试耗尽。
重试事件必须保持相同 event_id，避免重复通知；不无界重试。
不要声称 sent 就代表用户已收到邮件，或声称提醒接口能避免实验中断。

## 边界

服务和实验若都在 4090，整机掉线时它自身不能及时发信。独立外部监控另行配置。
不要为了这个技能修改 SSH、DNS、防火墙、别的服务或获取服务器凭据。
发布和服务器维护依照该项目 AGENTS.md 以及另行授权的 yun 工作流。
